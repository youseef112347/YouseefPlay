# YOUSEEF PLAY

تطبيق مشغل موسيقى محلي بتصميم زجاجي (Glassmorphism)

## الألوان
- بنفسجي: #7C3AED / #6B21A8
- أسود: #0F0F0F
- تصميم زجاجي شفاف مع Blur

## طريقة التشغيل

### 1. تثبيت المتطلبات
```bash
npm install
```

### 2. تشغيل التطبيق على الهاتف (تجربة سريعة)
```bash
npx expo start
```
ثم امسح الـ QR Code باستخدام تطبيق **Expo Go** من متجر جوجل أو آب ستور.

### 3. بناء ملف APK جاهز
```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
```

بعد ما البيلد يخلص هتلاقي لينك تحميل الـ APK مباشرة.
